Items no automation can verify. Tick with the app installed on the 12 mini.

1. [ ] Recapture fixtures: phone UNLOCKED, face-up, ~3 min. Then re-run
       scripts/calibrate.py; paste PTC/shutter tables into CALIBRATION.md.
2. [ ] Photograph a ColorChecker 24 under D65-ish light (probe app), then
       scripts/colorcheck.py — Tier 1 colour fidelity.
3. [ ] Manual Revert check in Apple Photos: revert one pikicam edit, confirm
       the DNG renders as first captured.
4. [ ] VoiceOver pass on camera + library: legibility over a bright scene.
5. [ ] Haptic bench: matrix select (rigidImpact), dial detent (selection),
       shutter (rigidPop) feel distinct.
6. [ ] 5-minute recording soak: device thermal state observed; report
       p95/p99 frame times if any stutter is felt.
